# Fallback PR template

Use this only when the repo has no PR template of its own.

```markdown
## Summary
One or two sentences: what changed and why.

## Changes
- Bullets grouped by area, each naming the behavior change, not the file.

## Diagram
(only if it earns its place; see "Choose a diagram" in the skill)

## Testing
What was run, what passed, what is still unverified.

## Demo
(only for user-visible changes with screenshots or a video; see "Media" in the skill)

## Notes
Rollout, migrations, risks, follow-ups. Omit if none.
```
